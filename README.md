# Волшебные дверцы — SH, CH, TH, PH

Первый рабочий каркас игры для младших школьников. Откройте `index.html` в браузере или разместите файлы в корне GitHub Pages. Сборка и зависимости не нужны.

## Как играть

1. Нажмите «Начать игру» и выберите одну из четырёх дверей.
2. Дверь откроется; прозвучит звук сочетания. Нажмите на каждое слово, чтобы услышать его и увидеть транскрипцию с переводом.
3. После трёх слов появится кнопка возврата к дверям. Кнопка «К дверцам» доступна и раньше.

## Файлы

- `index.html` — три экрана и элементы интерфейса.
- `styles.css` — внешний вид и мобильная версия.
- `data.js` — сочетания, слова, переводы и IPA; здесь меняют учебный материал.
- `audio.js` — загрузка MP3 и запасная озвучка средствами браузера.
- `app.js` — переходы, открытие двери и прогресс прослушивания.
- `assets/audio/` — место для записанной озвучки.

## Озвучка

Сейчас при отсутствии MP3 браузер произносит английские слова через Speech Synthesis. Голос и точность звука зависят от устройства; сочетание букв может читаться как название букв. Для гарантированного учебного произношения запишите короткие MP3 `assets/audio/sh/sound.mp3`, `assets/audio/ch/sound.mp3`, `assets/audio/th/sound.mp3`, `assets/audio/ph/sound.mp3`; для слов используйте, например, `assets/audio/sh/ship.mp3`. Скрипт автоматически использует файл, если он доступен. `assets/audio/door-open.mp3` — отдельная точка для скрипа двери. Для TH нужны отдельные варианты [θ] и [ð] при дальнейшем расширении обучения. Фактическое прослушивание сейчас отмечается по нажатию карточки, поскольку запись MP3 ещё не подготовлена.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку с файлами и папку **/(root)**. После публикации адрес будет `https://mamasha1804-lab.github.io/phonics-sh-ch-ph-th/`.
